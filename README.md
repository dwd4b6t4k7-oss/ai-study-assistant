# StudyPilot — AI Study Assistant

An AI-powered study assistant designed for students. The first release contains a polished responsive dashboard and a functional demo study workflow. The AI backend, document analysis, quizzes, flashcards, and progress persistence can be connected in the next development stage.

## Tech stack

- React + Vite
- JavaScript
- CSS
- OpenAI API (planned server-side integration)

## Run locally

```bash
npm install
npm run dev
```

Never put an OpenAI API key in frontend code. API keys belong in a server-side environment variable.

## Planned features

- AI tutor with subject and difficulty controls
- Explain, summarize, quiz, and flashcard modes
- PDF/notes upload and question answering
- Quiz scoring and study progress
- Student dashboard and saved study sessions
